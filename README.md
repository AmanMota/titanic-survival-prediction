# 🚢 Titanic Survival Prediction

## 📌 About Project
A Machine Learning project that predicts whether a passenger survived the Titanic disaster based on passenger details such as age, gender, passenger class, and fare.

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## ⚙️ Workflow
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Survival Prediction

## 📊 Dataset
[Kaggle Titanic Dataset](https://www.kaggle.com/competitions/titanic/data)

## 🎯 Objective
To understand and implement the Machine Learning workflow using a real-world classification problem.
